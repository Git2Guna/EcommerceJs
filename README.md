# 🧩 Green Shop

**Green Shop** is a modern, interactive e-commerce website built with **HTML, CSS, and JavaScript**. It allows users to browse products, search by keywords, add items to the cart, and track orders using **localStorage**. Perfect for demonstrating a front-end shopping experience without a backend.  

---

## 🎯 Purpose
Create a fully functional online shop that offers:  
- Product browsing & search 🔍  
- Cart functionality with localStorage 🛒  
- Dynamic product details & ratings ⭐  
- Promotional banners & featured collections 🎉  

---

## 🛠️ Features
- Search bar for products & brands 🔎  
- Product pages with images, prices, ratings, and descriptions 🛍️  
- Add to cart functionality saved in **localStorage** 💾  
- Cart icon with dynamic item count  
- Responsive design for desktop and mobile devices 📱💻  
- Multiple banners, deals, and promotional sections 🎁  
- Footer with contact info, social links, and app install links 📞  



## 🧩 Problem-Solving
- **Persistent cart:** Used `localStorage` to save cart items across sessions 🛒  
- **Dynamic product display:** Render products dynamically based on data arrays  
- **Search functionality:** Filter products based on keywords 🔍  
- **Cart counter:** Update icon in real-time as items are added
